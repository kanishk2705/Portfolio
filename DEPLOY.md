# Deployment Guide — Render

## Prerequisites

- GitHub account with the project repository
- Render account (render.com)
- `npm run build:db` and `npm run seed` run on every deploy (both only add what is missing, so your content is never overwritten)

---

## Step 1 — Push to GitHub

```bash
git init
git add .
git commit -m "Initial commit — portfolio platform"
git remote add origin https://github.com/YOUR_USERNAME/ai-ml-portfolio.git
git push -u origin master
```

---

## Step 2 — Create a Render Web Service

1. Go to **render.com → New → Web Service**
2. Connect your GitHub repository
3. Render will auto-detect `render.yaml` — review and confirm settings

Or configure manually:

| Setting | Value |
|---|---|
| **Runtime** | Node 24 (pinned in `package.json` → `engines`) |
| **Branch** | `master` |
| **Build Command** | `npm install && npm run build:db && npm run seed` |
| **Start Command** | `npm start` |
| **Instance Type** | Starter ($7/mo) — needed for persistent disk |
| **Region** | Oregon (or nearest to your users) |

---

## Step 3 — Add Persistent Disk

> ⚠️ **Critical**: Without a persistent disk your SQLite database and uploaded files are wiped on every deploy/restart. The free tier does NOT support persistent disks.

1. In your Render service → **Disks → Add Disk**
2. **Name:** `portfolio-data`
3. **Mount Path:** `/var/data`
4. **Size:** 1 GB (sufficient for years of use)

---

## Step 4 — Set Environment Variables

In Render → Environment, add:

```
NODE_ENV=production
PORT=10000
DATABASE_PATH=/var/data/portfolio.db
UPLOADS_PATH=/var/data/uploads
SITE_URL=https://your-domain.onrender.com

JWT_SECRET=<generate: node -e "console.log(require('crypto').randomBytes(48).toString('hex'))">
CSRF_SECRET=<generate: same command, different value>
JWT_EXPIRES_IN=7d

ADMIN_EMAIL=your@email.com
ADMIN_PASSWORD=your-secure-password

MAX_IMAGE_SIZE_MB=8
MAX_VIDEO_SIZE_MB=200
MAX_DOCUMENT_SIZE_MB=20
```

> **JWT_SECRET** and **CSRF_SECRET** can be auto-generated by Render if you use `generateValue: true` in `render.yaml` — they're already configured that way.

---

## Step 5 — First Deploy

Render will automatically:
1. Run `npm install`
2. Run `npm run build:db` (creates `/var/data/portfolio.db` from `schema.sql`)
3. Run `npm run seed` (creates your admin user from `ADMIN_EMAIL` + `ADMIN_PASSWORD`, plus the default skills, certificates and settings on an empty database)
4. Start the server

Seeding never overwrites anything you have edited in the admin panel.

---

## Step 6 — Verify

1. Visit `https://your-domain.onrender.com` → homepage loads
2. Visit `/admin/login` → login with your credentials
3. Visit `/sitemap.xml` → sitemap renders
4. Visit `/robots.txt` → robots file renders

---

## Step 7 — Custom Domain (optional)

1. Render → your service → **Custom Domains → Add Custom Domain**
2. Add your domain (e.g. `kanishk.dev`)
3. Update your DNS with the CNAME Render provides
4. Update `SITE_URL` env var to your custom domain
5. Render auto-provisions SSL via Let's Encrypt

---

## Uploading Media

Uploaded files (thumbnails, images, PDFs) are stored in:
```
/var/data/uploads/images/
/var/data/uploads/videos/
/var/data/uploads/documents/
```

The location comes from the `UPLOADS_PATH` environment variable (already set in `render.yaml`).
Locally it defaults to the repo's `uploads/` folder.

---

## Local Development

```bash
git clone https://github.com/YOUR_USERNAME/ai-ml-portfolio.git
cd ai-ml-portfolio
npm install
cp .env.example .env
# Edit .env with your values
npm run build:db
npm run seed
npm run dev        # starts with nodemon on port 3000
```

Visit:
- `http://localhost:3000` — portfolio homepage
- `http://localhost:3000/admin/login` — admin panel
- `http://localhost:3000/sitemap.xml` — sitemap
